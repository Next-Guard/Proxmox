# Contributing / Contribuire

**English** – Thank you for helping Proxmox Community grow! The full contribution guide, with the guide template and the rules for screenshots, sensitive data and languages, is on the website: <https://proxmox.community/contributing/>. In short: open an issue for mistakes and questions, or fork the repository, add or edit Markdown files in `docs/en/` and/or `docs/it/`, check them with `mkdocs build --strict` and open a pull request.

**Italiano** – Grazie per aiutare Proxmox Community a crescere! La guida completa per contribuire, con il modello di guida e le regole su screenshot, dati sensibili e lingue, è sul sito: <https://proxmox.community/it/contributing/>. In breve: apri una issue per errori e domande, oppure fai il fork del repository, aggiungi o modifica i file Markdown in `docs/it/` e/o `docs/en/`, verificali con `mkdocs build --strict` e apri una pull request.

Contributions are published under CC BY-SA 4.0 (content) and MIT (code). / I contributi sono pubblicati con licenza CC BY-SA 4.0 (contenuti) e MIT (codice).
